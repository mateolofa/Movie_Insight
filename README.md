# 🎬 Movie Insight - Sistema de Gestión y Visualización de Cine

![C#](https://img.shields.io/badge/C%23-.NET-purple) ![Windows Forms](https://img.shields.io/badge/UI-Windows%20Forms-blue) ![Status](https://img.shields.io/badge/Estado-Completado-green)

Aplicación de escritorio desarrollada en **C# (.NET)** para simular la gestión operativa de un cine y realizar análisis estadísticos sobre la visualización de películas y métricas mensuales.

---

## 📌 Descripción del Proyecto

**Movie Insight** fue diseñado como un proyecto académico enfocado en la aplicación práctica de lógica de programación, estructuras de datos avanzadas y separación de capas de software. Permite registrar géneros, procesar visualizaciones por mes y consultar métricas clave para la toma de decisiones.

---

## 🚀 Funcionalidades Clave

* **Gestión de Datos:** Registro y control de películas, géneros y métricas de audiencia.
* **Análisis Estadístico:** Módulos de consulta para calcular promedios, máximos y tendencias de visualización mensuales.
* **Interfaz Gráfica (GUI):** Diseñada en **Windows Forms** para ofrecer una experiencia intuitiva al usuario.
* **Lógica Separada:** Desacoplamiento entre la interfaz de usuario y la lógica de negocio para mantener un código limpio y escalable.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** C# (.NET)
* **Interfaz de Usuario:** Windows Forms
* **Estructuras de Datos:** Structs, Arrays y Matrices bidimensionales para el procesamiento de información en memoria.
